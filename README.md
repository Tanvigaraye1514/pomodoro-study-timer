# Pomodoro Timer

## About the Project
The Pomodoro Timer is a productivity web application that helps users manage their time using focused work sessions and short breaks. It is designed to improve concentration and make study or work sessions more organized.

## Features
- 25-minute focus sessions
- 5-minute short breaks
- 15-minute long breaks after every 4 completed focus sessions
- Start, pause, and reset controls
- Automatic switching between focus and break sessions
- Sound or alert notification when a session ends
- Daily count of completed focus sessions
- Browser tab title updates with the timer
- Saves settings and session count using local storage

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the Pomodoro Timer website.
2. Click Start to begin a focus session.
3. Pause or reset the timer whenever needed.
4. Take breaks when the timer switches sessions automatically.
5. Track your completed focus sessions throughout the day.
